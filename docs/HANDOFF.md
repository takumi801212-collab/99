## 4. 確定タグライン

> # 値上げには、デカ盛りで。

**保険案（社内で止まった場合）**: 「物価高には、デカ盛りで。」
文字数・改行位置・組み方が同一なので、**版下を作り直さず1語だけ差し替えられます**。

### 掲出体系（POP三層）

| 層 | 掲出 | 距離／接触 | コピー | 更新 |
|---|---|---|---|---|
| 第1層 | 入口・什器上部・大判 | 3–5m／0.5秒 | 値上げには、／デカ盛りで。 | 不変 |
| 第2層 | 売場什器・棚上ボード | 1–2m／1–2秒 | その値段で、そのデカさ。 | 不変 |
| 第3層 | 商品札・プライスカード脇 | 30cm／2–3秒 | カツ、2枚。 ¥538 | **毎回** |

版を作り直すのは第3層だけ。第1層・第2層は毎回そのまま使い回します。

### 商品札コピーの型（第3層）

形容詞（大きい・たっぷり・ボリューム満点）は**全型で禁止**。

- **型A｜数える** `〔数えられる事実〕。＋価格` → 「カツ、2枚。」最優先
- **型B｜身体** `〔身体感覚〕。＋価格` → 「片手に、のらない。」**実物で成立確認が必須**
- **型C｜価格直球** `これで、〔価格〕円。` → 迷ったらこれ

### タグラインと企画名のロックアップ

同じ級数・同じ書体で縦に並べない（「デカ盛り」が2回出て、同じことを2回言っているように読まれる）。
企画名の級数は**タグラインの1/4以下**、無彩色、下端。開催期間と同じ「情報」の階層に落とす。

## 6. 再検討しないこと（判断済み）

同じ議論を繰り返さないための記録です。

### 依頼者の初期3案を採用しなかった理由

- **価格以上の満足感！** ── 論旨は正しいが**誰にでも言える**。LS100でなければならない理由がゼロ。「満足感」は送り手側の抽象名詞で、極めて視覚的な企画にいちばん非視覚的な語を当てている
- **見て驚き、食べて満足！** ── 構造（視覚の驚き→体験の充足）は3案中最良だが語がすべて常套句。価格の話が消え、物価高文脈から切り離される。※商品札用サブコピーとしてなら機能する
- **お得も満足も、限界突破。** ── 「限界突破」はゲーム／スポーツ由来の借り物で50代以上4割の生活実感と接続しない。毎回「限界」を謳うと反復耐性が最も低い

### 検討して見送った案

| 案 | 理由 |
|---|---|
| 100円台で、ここまで盛る。 | 事実と齟齬。対象商品は税込157〜538円 |
| 安いのに、デカい。 | 「安い」の自称は「価値に見合った価格」への転換方針に逆行 |
| 腹いっぱい、値段そのまま。 | 3社と同じ土俵。かつ**今回は法務上使用不可** |
| 小さくなる世の中で、デカくする。 | 主張は同系で優秀だが14字は店頭に長く、理屈っぽい |
| 節約なのに、満腹。 | 「節約」が安っぽく、デカ盛りの高揚感を消す |
| 盛るのは、店。挑むのは、あなた。 | 客に挑戦を強いる構図が節約パパ・ママ層と相性が悪い |

### 使ってはいけない語（法務・前提6由来）

お値段そのまま／価格据え置き／◯%増量／1.5倍／大幅増量／通常品より／前回より／お得／実質値下げ／激安／業界最大／日本一／No.1／大きい／たっぷり／ボリューム満点
